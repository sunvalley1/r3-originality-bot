Claude Code: the trading routine is a Claude Code routine (claude.ai, Code, Routines); its setup run is a Run now of
that same routine with a setup prompt, not a second routine. You cannot create the cloud environment or type its key
variables for the person: [SETUP.md](SETUP.md) step 6 says what they click and paste. You may create or update the
routine with `/schedule` once they ask you to, and start it now (a trade now, `/schedule run`) when they ask: the routine's run-now, never a one-time
schedule, because a routine holds one schedule and a one-time one would replace its twice-daily cron. If they
chose ChatGPT (SETUP.md step 0), there is no routine: their cloud or their computer runs a Codex task instead.
